# chatpipe

Конвейер, который превращает историю чатов с ИИ в сухие служебные документы.

* **Этап 1** (`run_stage1.py`): файл экспорта -> стандартные карточки + отчёт.
* **Этап 2** (`run_stage2.py`): карточки -> метки-якоря (словарь понятий, правила, ручная разметка) -> пачки для ИИ в XML.

Нужен только Python 3.8+ (стандартная библиотека). Для русских начальных форм слов желательно
`pip install pymorphy3 pymorphy3-dicts-ru`; без неё программа работает в простом режиме.

## Структура

```
run_stage1.py                      запуск этапа 1
run_stage2.py                      запуск этапа 2
chatpipe_user-settings.jsonc       файл настроек (с комментариями к каждому полю)
examples/                          примеры словаря и правил (посмотреть формат)
tests/test_chatpipe.py             автоматические проверки
chatpipe/
    __init__.py                    карта пакета, префикс имён файлов, версия
    names.py                       все имена файлов программы
    schema.py                      ДОГОВОР между стадиями (карточка, проверка, чтение/запись .jsonl)
    settings.py                    файл настроек (JSON с комментариями)
    text_tools.py                  HTML -> Markdown, хэш, деление Markdown на текст и код
    redaction.py                   маскирование секретов
    adapters/                      "переводчики" форматов экспорта (реестр + gemini_takeout_html.py)
    stage1_report.py, stage1_ingest.py                 этап 1
    dictionary.py, annotations.py, keywords.py,
    rules.py, xml_render.py, bundles.py,
    console.py, stage2_session.py, stage2_menus.py,
    stage2_label.py                                    этап 2
```

## Запуск

Из папки проекта:

```bash
# Этап 1
python3 run_stage1.py MyActivity2.html -o output
python3 run_stage1.py --list-profiles

# Этап 2
python3 run_stage2.py                    # меню разметки
python3 run_stage2.py --stats            # статистика
python3 run_stage2.py --apply-rules      # применить правила без вопросов (для автозапуска)
python3 run_stage2.py --compose          # собрать пачки из карточек со статусом ready

# Настройки и проверки
python3 -m chatpipe.settings             # создать файл настроек с комментариями
python3 -m unittest discover -s tests -v # запустить все автоматические проверки
```

## Где лежат данные

| Что | Где | Можно пересоздать? |
|---|---|---|
| карточки, отчёты, пачки для ИИ | папка `output/` | да |
| словарь, аннотации (метки), правила, тексты справки | папка `user-data/` | **нет** (ваша ручная работа, делайте резервные копии) |

## Статусы карточек

`new` -> `proposed` (предложено правилом) -> `tagged` (метки поставлены) -> `ready` (вы явно поставили
флаг "готово к компоновке"); `skipped` - карточка не нужна. В пачки попадают только `ready`.
Автоматика не трогает карточки, с которыми уже работал человек.

## Правила именования

* модули кода: snake_case, без версии, префиксом служит папка пакета;
* файлы данных: `[префикс]_[смысл]_[стадия].[расширение]`;
* версия живёт внутри файлов (`schema_version`, `__version__`), а не в именах.

## Как добавить новый источник чатов

См. начало `chatpipe/adapters/__init__.py`: новый файл-адаптер с четырьмя обязательными деталями
плюс одна строка в реестре. Остальной конвейер менять не нужно.

## Подробная справка внутри меню

Тексты справки берутся из файлов `user-data/chatpipe_help_<тема>_stage2.txt`
(темы: `main`, `labeling`, `rules`, `dictionary`). Если файла нет, показывается краткая встроенная справка.
